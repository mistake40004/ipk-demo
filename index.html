4. Проектная деятельность: тема и техническое задание

Предмет «Учебная практика» (4 семестр). Тема сгенерирована нейросетью GigaChat с учётом специализации студента и подтверждена к выполнению.

Тема: Создание онлайн-магазина с использованием популярных фреймворков (Vue.js, React)

Источник генерации: GigaChat

Цель

Создать функциональный онлайн-магазин с каталогом товаров, корзиной покупок и системой оформления заказов

Стек

HTML/CSS JavaScript Vue.js/React Node.js Git

Задачи

  • Разработать интерфейс магазина с помощью Vue.js/React
  • Реализовать серверную часть с помощью Node.js для обработки заказов и управления товарами
  • Интегрировать систему оплаты через популярные API платёжных сервисов
  • Создать административную панель для добавления, редактирования и удаления товаров
  • Подготовить документацию проекта и провести демонстрацию работы приложения
  • Создать репозиторий проекта в Git и оформить коммиты согласно стандартам разработки

Ожидаемый результат

Функциональный веб-сайт онлайн-магазина с возможностью просмотра каталога, добавления товаров в корзину, оформления заказа и администрирования товаров
